# Amigo Voice Assistant 🎙️🤖

## Overview

Amigo is a simple Python-based Voice Assistant that can listen to voice commands, respond using text-to-speech, search Wikipedia, and open popular websites and applications.

The assistant uses speech recognition to understand user commands and performs actions accordingly.

This project demonstrates the fundamentals of:
- Voice Recognition
- Text-to-Speech (TTS)
- Automation using Python
- Web Browser Integration
- Basic Artificial Intelligence Concepts

---

## Features

✅ Voice Command Recognition

✅ Text-to-Speech Responses

✅ Wikipedia Search Support

✅ Open Popular Websites

✅ Play Music via Spotify

✅ Open Local Disk Drives

✅ Launch WhatsApp

✅ Interactive Voice-Based Communication

---

## Technologies Used

- Python 3
- SpeechRecognition
- Pyttsx3
- Wikipedia API
- Webbrowser Module
- OS Module
